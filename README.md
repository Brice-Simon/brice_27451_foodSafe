# FoodSafe Inspect
Restaurant Hygiene Inspection and Re-Inspection Scheduler

INSY 8311 Final Practicum Project - Oracle Database and PL/SQL

## Student
Nsabimana Simon Brice - ID 27451

## Problem
Food safety inspectors often track restaurant visits on paper or spreadsheets, so they forget which businesses failed and when to return.

## Solution
An Oracle PL/SQL system that records inspections and violations, calculates scores and grades, creates re-inspection tasks for failed businesses, and flags overdue visits with a scheduler.

## Data source
City of Los Angeles Open Data, via Kaggle (LA Restaurant & Market Health Data):
https://www.kaggle.com/datasets/cityofLA/la-restaurant-market-health-data

## Planned innovation
Smart automation (scheduler, alerts, APIs)
